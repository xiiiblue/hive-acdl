# STD-007：开发验证规范

> 文档状态：Review
>
> 责任角色：Director

先确认采用项目的工具版本、当前设计和实际差异。macOS运行验证前设置`TMPDIR=/tmp`。先运行最接近修改的检查，再运行覆盖受影响关系的统一验证。

本规范库使用 Node.js 22 或更新版本，无第三方运行依赖：

```sh
npm run check
npm test
npm run diff:check
```

采用项目可以按风险建立 docs、code、platform 档位：文档检查结构和引用；代码检查相关模块及依赖；权限、持久状态、迁移、恢复和跨进程变化补充集成验证。不得仅按文件夹名认定通过。此仓库不提供产品代码档位调度器。

证据记录完整提交或输入摘要、比较基线、工具版本、命令、结果、失败、跳过及平台限制。预览不是验证通过，补写文档不能证明代码被重新验证。源输入变化后重新判断证据适用范围。

失败后保留原始错误，定点诊断并修复，再重跑失败的完整检查。不能隐藏失败、弱化检查或用无关检查替代。接受必需检查未运行或失败属于Director的具体风险决定。

测试使用新项目内的临时合成fixture；不得连接生产接口、使用真实业务数据或读取凭据。采用项目的数据库测试必须使用专用隔离库，并明确清理范围。本项目没有数据库、部署、SSH或生产接口依赖。

环境发布、正式版本、浏览器体验、容器宿主与本机工具测试分别证明不同范围；本机结果不证明其它环境已通过。
