# 提取来源与整理范围

本项目从HiveOS通用规范、完整研发流程手册与适用工具中提取整理，当前核对的来源是`xiiiblue/hive-os`提交`5d71f33176eb4ab4788e1c875b1a3eb3bf5bd22a`。首次提取基线是`3d3a634be5b401ef02740fdbebd00fcdc16fb2ff`，历史提取结果保留在[验证记录](VALIDATION.md)。

[机器清单](manifest.json)记录每份源文件的原始SHA-256、目标路径与删改；摘要对应原始字节，整理稿不宣称逐字相同。原始来源由有权访问者按固定提交核对，本仓库不打包未审阅的上游快照，公共读者也不需要取得来源访问权才能使用这里的材料。

## 收录内容

九项STD的通用规则、研发流程手册的方法摘要、Agent入口及PR模板思路；适用的设计追踪、分支检查、Issue关系、流程统计与Loop纯函数。模板由这些方法整理，不虚称来源中已有同名文件。

本次公开整理逐项比较来源变化：新增的HiveFlow目录和蜂巢副产物本机位置属于来源专用事实，不复制；通用命名与按实际影响验证的原则保留。规范保持Review，供采用项目按自身范围确认。

## 不收录的内容

- 业务源码、连接器、运行时、部署、真实测试产物与真实需求、设计、Issue或版本记录。
- 来源环境、历史业务材料、SSH、发布、备份恢复及验证档位调度器。
- 外部Issue写入、自动同步、自动结束Loop的执行器，及来源专有授权。
- 凭据、真实用户或群标识、私人消息、个人目录、环境地址与敏感运行信息。

## 本仓库新增与改写

公开教程、可运行教学示例、示例回归、只读离线CI及本仓库安全/贡献说明由本项目维护。`demo`使用合成需求与数据，写入独立`.tmp/`目录，不伪造业务验收。

通用STD移除来源专用链接、授权与旧历史批次；STD-007解释本项目工具验证要求；Loop库只提供模板和状态纯函数。统计时区由参数设置，默认UTC；Issue关系允许通用GitHub仓库。详细命令和限制见[工具与命令](../docs/03-工具与命令.md)。
